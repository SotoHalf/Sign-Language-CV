# Sign Language CV — Real-Time Sign Language Recognition

An experimental approach to real-time recognition system for the Sign Language using computer vision. Combines **MediaPipe HandLandmarker** for 21-point 3D hand skeleton detection, temporal landmark sequence normalization, and a **BiLSTM + Conv1D** neural network for gesture classification.

---

## Requirements

- Python 3.11
- Webcam (or video files for video-based input)
- GPU optional but recommended for training

---

## Installation

```bash
git clone https://github.com/<your-username>/sign-language-cv.git
cd sign-language-cv

python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

Besides the Python packages in `requirements.txt`, the GUI relies on PySide6 (Qt6), which needs certain **system libraries** for the Qt platform plugin to load correctly. These are not Python packages and must be installed through your OS package manager.

**Linux (Ubuntu/Debian):**

If the application fails to start with an error such as `qt.qpa.plugin: Could not load the Qt platform plugin "xcb"`, you are likely missing some system libraries. Installing the following usually resolves it:

​```bash
sudo apt install libxcb-cursor-dev libxcb-xinerama0 libxkbcommon-x11-0
​```

> The exact set of required libraries may vary between distributions and versions. In some setups only `libxcb-cursor-dev` is needed, while others require additional `xcb` packages. If the issue persists, the error message usually indicates which library is missing.

**Windows / macOS:**

Generally no extra system libraries are needed; `pip install PySide6` is enough.

For platform-specific details, see the official PySide6 documentation:
https://doc.qt.io/qtforpython-6/gettingstarted/index.html

## Configuration: `.env`

Copy `.env.example` and rename it to `.env` at the project root:

### Available variables

```dotenv
# ── Data paths ─────────────────────────────────────────────────────────────
DATA_PATH        = "data/processed/"   # Normalized CSVs (model input)
DATA_RAW_PATH    = "data/raw/"         # Raw landmark CSVs
DATA_LABELS_FILE = "data/labels.json"  # id → label map (future use)
MODELS_PATH      = "models/"           # Model directory

# ── Models ─────────────────────────────────────────────────────────────────
HAND_DETECTION_MODEL = "models/hand_landmarker.task"  # MediaPipe model (required)
SIGN_TRANSLATE_MODEL = "models/sign_lstm.keras"        # Trained gesture model
LABEL_ENCODER_FILE   = "models/sign_lstm_encoder.npy"  # Label encoder classes

# ── Capture parameters ─────────────────────────────────────────────────────
CAPTURE_FRAME_RATE_FPS   = 30   # Target capture FPS
CAPTURE_DURATION_SECONDS = 1    # Sequence duration in seconds
                                 # → n_frames = FPS × DURATION = 30 frames/seq

# ── MediaPipe landmark indices (do not change unless the model is updated)
HAND_TOTAL_LANDMARKS        = 21  # Total hand landmarks
HAND_LANDMARK_WRIST         = 0   # Wrist (position normalization origin)
HAND_LANDMARK_MIDDLE_FINGER = 12  # Middle fingertip
HAND_LANDMARK_THUMBCMC      = 1   # Thumb CMC (scale reference)
HAND_LANDMARK_PINCKYMCP     = 17  # Pinky MCP (scale reference)
```

> All paths are relative to the project root. `AppPaths.path()` resolves them automatically in both normal execution and when packaged with PyInstaller.

## Setting Up the Data Directories

```bash
# Linux / macOS
mkdir -p data/raw data/processed data/resources/lse_videos models
```

After collecting data, the `data/` folder will look like this:

```
data/
├── raw/
│   ├── A/
│   │   ├── abc123_1697000000_def456.csv   ← raw landmarks (N × 63)
│   │   └── ...
│   └── B/
│       └── ...
└── processed/
    ├── A/
    │   ├── abc123_1697000000_def456.csv   ← normalized + delta (N × 126)
    │   └── ...
    └── B/
        └── ...
```

Each CSV in `processed/` contains a sequence of `N` frames with **126 columns**:

| Columns | Description |
|---|---|
| `lm0_x … lm20_z` | Normalized position — 21 landmarks × (x, y, z) |
| `d0_x … d20_z` | Inter-frame delta (velocity) — 21 landmarks × (Δx, Δy, Δz) |

## Workflow

### 1 — Collect data

```bash
# Guided collection with reference video overlay (videos for each letter are not included)
python collect_webcam_guided.py

# Free-form webcam collection
python collect_webcam.py

# Extract landmarks from video files in data/resources/lse_videos/
python collect_video.py
```

### 2 — Review and clean recordings

```bash
python view_recordings.py
```

| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `←` / `→` | Previous / next recording |
| `S` | Sign selector dialog |

### 3 — Train the model

```bash
python train_model.py
# Outputs: models/sign_lstm.keras  and  models/sign_lstm_encoder.npy
```

### 4 — Real-time inference

```bash
python live_sign_to_text.py
```

| Key / Gesture | Action |
|---|---|
| `I` | Toggle inference on / off |
| `C` | Clear the text buffer |
| `confirm` gesture | Commit the pending sign to text |
| `delete` gesture | Delete last character (×3 = clear all) |
